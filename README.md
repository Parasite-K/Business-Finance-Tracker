# Business Finance Tracker

A Python project built to learn software engineering fundamentals while creating a useful finance management application for businesses.

## Current Features
- Add income transactions
- Add expense transactions
- Implemented all CRUD features
- Input validation
- Monthly, yearly financial reports.
- data persistence using JSON

## Technologies

- Python
- Git
- GitHub

## Planned Features

- Project based transactions.
- SQLite database
- Search and filtering
- FastAPI backend
- User accounts
- Business dashboard
- AI powered financial analysis

## Purpose

This project is being developed as a learning journey from a simple console application toward a production-ready business finance platform.
